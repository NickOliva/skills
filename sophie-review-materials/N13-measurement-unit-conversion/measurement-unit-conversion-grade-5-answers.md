# Worked Answer Key

## Page 1
1. Each meter contains $100$ centimeters. $6\times100=600$, so $6\text{ m}=600\text{ cm}$.
2. Each meter contains $1{,}000$ millimeters. $4{,}300\div1{,}000=4.3$, so $4{,}300\text{ mm}=4.3\text{ m}$.

## Page 2
1. Each kilogram contains $1{,}000$ grams. $7\times1{,}000=7{,}000$, so $7\text{ kg}=7{,}000\text{ g}$.
2. Each kilogram contains $1{,}000$ grams. $5{,}600\div1{,}000=5.6$, so $5{,}600\text{ g}=5.6\text{ kg}$.

## Page 3
1. $9\times1{,}000=9{,}000\text{ mL}$.
2. $2{,}750\text{ mL}=2\text{ L }750\text{ mL}=2.75\text{ L}$.

## Page 4
1. $7\times12=84$ inches.
2. $5\times3=15$ feet.

## Page 5
1. $6\times16=96$ ounces.
2. $3\times4=12$ quarts.

## Page 6
1. $4\times12+7=55$ inches.
2. $3\times3+2=11$ feet.

## Page 7
1. $3.6\times100=360$ cm.
2. $475\div100=4.75$ m.

## Page 8
1. Inches: a pencil is short, so inches give a useful-sized number.
2. Liters: a bathtub holds several liters; milliliters are too small and kiloliters too large.

## Page 9
1. $3\text{ m}=300\text{ cm}$, so $300>280$.
2. $2\text{ kg}=2{,}000\text{ g}$, so $2{,}000>1{,}950$.

## Page 10
